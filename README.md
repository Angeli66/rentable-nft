Rentable-NFT
A SIP-009 compliant NFT extended with rental mechanics, built with Clarity on the Stacks blockchain.
It allows NFT owners to rent out their NFTs for a specified fee and duration without transferring permanent ownership.

Features
Mint and own SIP-009 NFTs
Rent out NFTs for STX or token fees
Temporary usage rights assigned to renter
Automatic expiration after rental duration
On-chain logs for rentals and expirations
